# Project skill discovery

This repository keeps the canonical Cally skills under `skills/`.

For user requests about high-cost or hard-to-reverse life decisions, consider and read:

- `skills/cally-life-decision/SKILL.md`

For decisions about repairing, observing, separating, negotiating, divorcing, arranging assets, or leaving a marriage safely, also read:

- `skills/cally-marriage-crossroads/SKILL.md`

Follow each skill's linked public references only when relevant. Do not infer thresholds, exceptions, or proprietary rules that are not present in the public runtime.

Do not treat a factual query or emotion-only expression as a decision request. Immediate safety takes priority over long-term decision analysis.
