# Public Runtime Marriage Variables

只问会改变判断的问题，已知内容不重复询问。

## 优先变量

1. 是否存在即时危险、威胁、限制自由或求助能力。
2. 债务、资产、孩子、证据或程序风险是否正在扩大。
3. 用户现在真正要决定的动作、目标和时间窗口。
4. 可用资金、重要材料、安全住所、行动与通讯、照护和可信支持是否足以执行选项。
5. 关系问题持续多久，双方实际采取过哪些持续、可核实的行动。

## 改变证据

分别观察修复意愿与修复能力。意愿看是否承认具体问题、停止外推责任并承担改变成本；能力看是否能持续执行、具备现实条件，并在用户不满足其期待时仍尊重边界。

一次示好、道歉、保证书或短期体贴不能单独证明长期稳定改变。重点看持续兑现、实际成本、结构性变化和压力重新出现后的表现。

有收入，不等于现在就能顺利离开。没有收入，也不等于完全走不了。还要看住处、资金、照护和身边有没有可靠的人。
