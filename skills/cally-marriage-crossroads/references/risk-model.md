# Public Runtime Risk Model

## 优先级

风险高不高，不看问题一共有多少个。先看有没有哪件事，会让用户更难离开、求助或保护自己。

若存在即时暴力、严重威胁、限制人身自由或剥夺通讯/求助能力，暂停普通婚姻权衡，优先当地紧急资源、可信支持和不增加危险的安全安排。不要先争论法律或心理标签。

## 必查维度

- 人身安全与强制控制；
- 债务、共同责任和资产控制；
- 孩子安全、照护与冲突暴露；
- 证据或重要信息是否可能消失；
- 住所、资金、交通、通讯和支持是否足以执行计划；
- 继续等下去，麻烦或损失会不会变大。

双方都出现攻击性行为时，不自动认定责任相等。核实行为发生顺序、是否有人阻止离开或求助、行为功能、长期模式和实际伤害；事实不足时保留未知，不作法律定性。

区分客观期限与伴侣制造的压力。真实法律、财务、身份或合同期限应尽快由可靠渠道核实；单方面催促本身不足以支持难逆转动作。
